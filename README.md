### 📌 Overview & SEO Summary 🔍

Welcome to the definitive curated directory of **cloud migration discovery platforms**, **open-source dependency mapping tools**, and **cloud infrastructure assessment frameworks**. As organizations transition on-premises workloads to AWS, Microsoft Azure, and Google Cloud Platform (GCP), executing thorough discovery and dependency mapping is essential to mitigate architectural risks and prevent service downtime.

Whether you require enterprise-grade hyperscaler native tools (*AWS Application Discovery Service*, *Azure Migrate*, *Google Cloud Migration Center*), specialized enterprise platforms (*Flexera One*, *IBM Turbonomic*, *Device42*), or privacy-preserving open-source tools (*Cartography*, *Konveyor Tackle*, *Cloud Migration MCP*, *Mercator*, *SWAO*), this resource provides structured insights on pricing models, free tier limits, company valuations, and repository star metrics to accelerate your 7Rs cloud migration strategy. 📈

## 🔓 Open-Source GitHub Projects 🌟

*Sorted by GitHub_Stars_Count (Descending)* 📊

- **[Cartography](https://github.com/lyft/cartography)** [![Stars](https://img.shields.io/github/stars/lyft/cartography?style=social&color=white)](https://github.com/lyft/cartography/stargazers)  
  **Infrastructure asset and relationship mapping**, Apache-2.0 licensed. Consolidates infrastructure assets and dependencies into an intuitive Neo4j graph view. Supports 30+ platforms including AWS, Azure, GCP, Kubernetes, and Okta. Exposes hidden security and infrastructure dependency relationships essential for cloud migration wave planning. Python-based, battle-tested in enterprise production environments. 🗺️ 🐍

- **[Konveyor Tackle](https://github.com/konveyor/operator)** [![Stars](https://img.shields.io/github/stars/konveyor/operator?style=social&color=white)](https://github.com/konveyor/operator/stargazers)  
  **Application modernization & migration platform**, Apache-2.0 licensed (CNCF Sandbox Project). Provides automated portfolio discovery, static code analysis, and containerization suitability scoring. Features Pathfinder assessment questionnaires and source code analysis engines to accelerate rehosting, replatforming, and refactoring to Kubernetes. 🚢 ⚓

- **[Cloud Migration MCP](https://github.com/chrishorne74/cloud-migration-mcp)** [![Stars](https://img.shields.io/github/stars/chrishorne74/cloud-migration-mcp?style=social&color=white)](https://github.com/chrishorne74/cloud-migration-mcp/stargazers)  
  **MCP server for cloud migration assessment & 7Rs planning**, open-source. Evaluates workloads across 10 industry-standard criteria (business criticality, complexity, readiness, data sensitivity) with a built-in 7Rs decision engine. Includes 30+ architectural guardrails, wave planning algorithms, ROM cost estimation, and automated Draw.io diagram generation. 🚀 🤖

- **[Mercator](https://github.com/dbarzin/mercator)** [![Stars](https://img.shields.io/github/stars/dbarzin/mercator?style=social&color=white)](https://github.com/dbarzin/mercator/stargazers)  
  **Information system mapping and governance**, GPL-3.0 licensed. Aligned with ANSSI cybersecurity guidelines for mapping IT systems. Provides logical, physical, and administrative infrastructure views alongside CVE vulnerability integration and REST API export capabilities. PHP/Laravel backend supporting PostgreSQL and MySQL. 🏛️ 📁

- **[xmigrate](https://github.com/xmigrate/xmigrate)** [![Stars](https://img.shields.io/github/stars/xmigrate/xmigrate?style=social&color=white)](https://github.com/xmigrate/xmigrate/stargazers)  
  **Open-source multicloud migration & discovery framework**, Apache-2.0 licensed. Automates discovery and live server migration of physical and virtual machines to major cloud providers (AWS, Azure, OpenStack). Ideal for self-hosted environment assessment and migration execution. 🔄 ⚡

- **[SWAO (Accenture)](https://github.com/Accenture/SWAO)** [![Stars](https://img.shields.io/github/stars/Accenture/SWAO?style=social&color=white)](https://github.com/Accenture/SWAO/stargazers)  
  **AI-accelerated cloud workload compliance assessment**, open-source. Runs static code passes (~30 sec) and LLM architectural evaluations (3–8 min) to score migration workloads against GDPR, HIPAA, PCI DSS, and ISO 27001 compliance frameworks. Features TUI, CLI, MCP server, and PowerBI dashboards. 🛡️ 📊

## ⚠️ Disclaimer ℹ️

- This is a **community-curated** list — not exhaustive and not an explicit commercial endorsement. ℹ️
- **AWS Application Discovery Service & Azure Migrate** offer free native discovery, but target cloud resources (storage, compute, database instances) incur standard consumption costs. ☁️
- **Google Cloud Migration Center** defaults to a 5-year timeline assessment — customize target completion velocities based on enterprise workloads. 🌐
- **Open-source projects** (Cartography, Konveyor, Cloud Migration MCP, Mercator) require self-hosted installation and infrastructure configuration. Always validate discovery outputs in staging environments before committing to enterprise migration timelines. 🛠️
